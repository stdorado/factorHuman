# Factor Humano 2026

Sitio del evento de ciberseguridad **Factor Humano 2026**.
Jueves 26 de noviembre de 2026 · Centro Cultural de Lezama · con el acompañamiento de la Subsecretaría de Seguridad y Defensa Civil, Municipalidad de Lezama.

Sitio estático (un solo `index.html`), sin build. Se publica en Vercel desde la rama `main`.

## Activar la inscripción
En `index.html`, buscá `var INSCRIPCION_URL = "";` y pegá el enlace `/exec` de la aplicación web de Apps Script.
